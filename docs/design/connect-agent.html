Connect your agent

Your AI agent reads your re:Invent favorites and reservations from AWS and puts them here. Hallway never sees your AWS sign-in.

1. Add the AWS Events MCP server

claude mcp add --transport http \
  aws-events https://api.awsevents.com/mcp

Your agent signs you in with your AWS Builder ID the first time it uses it. Other agents: add the same URL as a remote MCP server.

2. Add Hallway with a token

Token for "Claude Code on laptop" Copy it now. Hallway shows it once. 
claude mcp add --transport http \
  hallway https://hallway.example/mcp \
  --header "Authorization: Bearer hw_7Kq2mP9xVt4cRw8LnZ3bYf6s"

The token acts as you and nothing more. Revoke it any time in Settings.

3. Ask your agent

Put my re:Invent 2026 schedule on Hallway.

Ask again whenever you change your favorites or reservations. A sync replaces what the last one sent and keeps what you added or hid here.
